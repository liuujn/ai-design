# 菜单管理画面

## 1. 基本信息

- 画面ID(路径): /menu
- 画面名: 菜单管理

## 2. 页面概要

- 本页面用于管理系统侧边栏菜单，支持菜单的搜索、新建、编辑和删除操作。
- 菜单列表显示所有菜单项，支持按关键词和状态进行搜索。
- 菜单信息包含：名称、图标(SVG)、页面标题、页面路径、排序序号、分隔线标识、状态等。
- 菜单数据由主页侧边栏动态加载显示。

## 3. 页面布局

### 3.1 菜单列表画面

#### 补充说明

- 上部：操作按钮区域（新建）
- 中部：搜索条件（关键词、状态）
- 下部：菜单列表DataTable + 分页器
  - 菜单名称显示为可点击链接
  - 状态使用标签组件显示不同颜色
  - 分隔线标识显示"是/否"
  - 排序序号使用数字显示

### 3.2 菜单编辑画面

#### 补充说明

- 上部：页面标题
- 中部：菜单信息编辑表单
  - 菜单名称（必填）
  - 图标（SVG代码，带预览）
  - 页面标题
  - 页面路径（HTML文件名）
  - 排序序号
  - 分隔线（复选框，勾选后作为分组标题）
  - 状态（启用/停用）
- 底部：保存/取消/返回按钮

## 5. 处理功能详细

### 5.1 初始显示处理

- 调用时机: 菜单列表页面初次显示时
- 处理内容: 自动加载菜单列表

### 5.2 搜索处理

- 调用时机: 搜索按钮点击时
- 处理内容: 携带搜索条件调用菜单列表API

### 5.3 新建跳转处理

- 调用时机: 新建按钮点击时
- 处理内容: 跳转至编辑画面，空白表单，模式为创建

### 5.4 编辑跳转处理

- 调用时机: 点击编辑按钮或菜单名称时
- 处理内容: 跳转至编辑画面，加载菜单详情数据

### 5.5 保存处理

- 调用时机: 点击保存按钮时
- 处理内容:
  - 校验菜单名称必填
  - 创建模式：POST /api/v1/menus
  - 编辑模式：PUT /api/v1/menus/{id}（附带updatedAt）
  - 保存成功后返回菜单列表页面

### 5.6 删除处理

- 调用时机: 点击列表中的删除按钮时
- 处理内容:
  - 显示删除确认对话框
  - 确认后调用菜单删除API（DELETE /api/v1/menus/{id}）
  - 请求参数：updatedAt（乐观LOCK）
  - 成功后刷新列表

### 5.7 状态切换处理

- 调用时机: 点击启用/停用按钮时
- 处理内容:
  - 显示状态变更确认对话框
  - 确认后调用菜单状态变更API（PATCH /api/v1/menus/{id}/status）
  - 成功后刷新列表

### 5.8 侧边栏联动

- 主页每次加载时调用 `GET /api/v1/menus/sidebar` 获取菜单列表
- 菜单添加/修改/删除后，刷新主页即可看到最新菜单
