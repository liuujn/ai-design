# 系统菜单表设计

## 系统菜单主数据

|項目ID|項目名|型|長さ|NOT NULL|デフォルト値|備考|
|---|---|---|---|---|---|---|
| id | 菜单唯一标识 | VARCHAR | 36 | TRUE | | UUID PK |
| parent_id | 父菜单ID | VARCHAR | 36 | FALSE | | 层级关系 |
| label | 菜单名称 | VARCHAR | 100 | TRUE | | 显示名称 |
| icon | 图标(SVG) | VARCHAR | 2000 | FALSE | | SVG代码 |
| page_title | 页面标题 | VARCHAR | 100 | FALSE | | 顶栏显示 |
| page_src | 页面路径 | VARCHAR | 500 | FALSE | | iframe加载 |
| sort_order | 排序序号 | NUMBER(5) | | FALSE | 0 | 升序排列 |
| is_divider | 分隔线标识 | NUMBER(1) | | FALSE | 0 | 1=分隔线 0=菜单项 |
| status | 菜单状态 | VARCHAR | 20 | TRUE | 'active' | active/inactive |
| created_at | 创建时间 | TIMESTAMP | | TRUE | CURRENT_TIMESTAMP | |
| created_by | 创建者ID | VARCHAR | 36 | TRUE | | |
| updated_at | 更新时间 | TIMESTAMP | | TRUE | CURRENT_TIMESTAMP | |
| updated_by | 更新者ID | VARCHAR | 36 | TRUE | | |
| is_deleted | 逻辑删除标志 | NUMBER(1) | | TRUE | 0 | |

- Table Name: sys_menus
- PK: sys_menus_pk
- INDEX: idx_sys_menus_parent (parent_id)
- INDEX: idx_sys_menus_status (status)
- INDEX: idx_sys_menus_sort (sort_order)
