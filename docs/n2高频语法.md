# N2 高频语法

## あげく（に）／挙句に

**接续：** Vた／名ーの ＋ あげく（に）

**语法意思：** 表示结果，后项结果一般带有消极意义。最后…／最终…／终于…

**注意：** 前面通常跟「～お思う」「～と悩む」「～迷う」「～困る」「～考える」搭配使用

**例句：**
1. いろいろ考えたあげく、彼女と別れることにした。
   → 考虑了很多之后，最终决定和她分手。
2. さんざん迷ったあげく、A社に就職することにした。
   → 犹豫了很久之后，最终还是决定去A公司工作。
3. 彼は長い間悩んだあげく、会社を辞めた。
   → 他烦恼了很久之后，最终辞去了工作。
4. 激しく議論したあげく、何の結論も出なかった。
   → 激烈讨论之后，最终什么结论都没有得出。
5. 無理なダイエットを続けたあげく、体調を崩してしまった。
   → 持续进行不合理的减肥，最后把身体搞坏了。
6. 彼の嘘がばれたあげく、周りの人すべてを信頼しなくなった。
   → 他的谎言被揭穿后，最终不再信任周围所有的人。
7. 借金を重ねたあげく、ついに自己破産した。
   → 负债累累之后，最终宣告个人破产。

## あまり（に）

**接续：** V原形／形2＋な／名＋の ＋ あまり（に）

**语法意思：** 表示程度（高），常与表示感情的词一起使用。由于过于……因而……（结果消极/积极均可）

**注意：** 「あまり…ない…」表示"不太…"

**例句：**
1. 彼は驚きのあまり、言葉も出なかった。
   → 他因为过于惊讶，说不出话来。
2. 彼女は嬉しさのあまり、涙を流した。
   → 她因为过于高兴，流下了眼泪。
3. 忙しさのあまり、友達に連絡するのを忘れてしまった。
   → 因为太忙，忘了联系朋友。
4. 心配のあまり、夜も眠れなかった。
   → 因为太担心，晚上都睡不着。
5. 彼は怒りのあまり、机を叩いた。
   → 他因为过于愤怒，拍了桌子。
6. 悲しみのあまり、彼は何も食べようとしなかった。
   → 他因为过于悲伤，什么都不想吃。
7. 彼女は感動のあまり、その場で泣き出してしまった。
   → 她因为过于感动，当场哭了出来。

## ～以上（は）

**接续：** V／形1／形2的名词修饰形／形2・名＋である ＋ 以上（は）

**语法意思：** 前项是确定的事实，后项常接表示决心、义务、建议、推量等表达方式，表明说话人的意志。既然……就……

**例句：**
1. 日本に留学する以上、日本語をしっかり勉強したい。
   → 既然要去日本留学，就想好好学习日语。
2. 約束した以上、必ず守らなければならない。
   → 既然约好了，就必须遵守。
3. 学生である以上、勉強を第一に考えるべきだ。
   → 既然是学生，就应该把学习放在第一位。
4. 生きている以上、何かしなければならない。
   → 既然活着，就必须做些什么。
5. この仕事を引き受けた以上、最後まで責任を持ってやります。
   → 既然接下了这份工作，就会负责到底。
6. 親である以上、子供の面倒を見るのは当然だ。
   → 既然是父母，照顾孩子是理所当然的。
7. 試合に出る以上、勝ちたいと思う。
   → 既然参加比赛，就想赢。

## 一方／一方で（は）／反面／半面

**接续：** V／形1／形2的名词修饰形 ＋ 一方／一方で（は）／形2・名＋である ＋ 一方／一方で（は）

**语法意思：** 一方面……另一方面……／一边……一边……

**例句：**
1. 彼は教師である一方、小説家としても活躍している。
   → 他一方面是老师，另一方面作为小说家也很活跃。
2. 日本は経済が発展している一方で、環境問題が深刻になっている。
   → 日本经济在发展的同时，环境问题也日益严重。
3. 彼女は厳しい反面、とても優しいところもある。
   → 她很严厉，另一方面也有非常温柔的地方。
4. この車はデザインが優れている一方、価格が高い。
   → 这辆车设计出色，但价格也很高。
5. 都会は便利な半面、自然が少ない。
   → 城市很方便，但另一方面自然很少。
6. 彼はお金持ちである一方で、幸せではないようだ。
   → 他虽然很有钱，但似乎并不幸福。
7. この仕事はやりがいがある一方で、ストレスも大きい。
   → 这份工作有意义，但压力也很大。

## 一方だ

**接续：** V原形 ＋ 一方だ

**语法意思：** 表示某种倾向、状态等朝着一个方向不断发展（积极/消极均可）。不断……／越来越……

**例句：**
1. 最近、円高が進む一方だ。
   → 最近日元不断升值。
2. 医療技術は進歩する一方だ。
   → 医疗技术不断进步。
3. 交通事故は増える一方だ。
   → 交通事故不断增加。
4. 彼の日本語は上達する一方だ。
   → 他的日语越来越好。
5. 環境汚染は深刻になる一方だ。
   → 环境污染越来越严重。
6. 仕事は忙しくなる一方で、休む暇もない。
   → 工作越来越忙，连休息的时间都没有。
7. この国の人口は減る一方だ。
   → 这个国家的人口不断减少。

## 上で（は）／上／上は／上も

### 句型一

**接续：** V原形／名＋の ＋ 上で（は）

**语法意思：** 在……方面／在……上

**例句：**
1. 日本語の上では、彼のほうが優れている。
   → 在日语方面，他更优秀。
2. 仕事の上で、いろいろな人と出会った。
   → 在工作上，遇到了各种各样的人。
3. 法律の上では問題ない。
   → 在法律上没有问题了。
4. 安全の上では、この車は信頼できる。
   → 在安全方面，这辆车是值得信赖的。

### 句型二

**接续：** Vた／名ーの ＋ 上で

**语法意思：** 在……之后

**例句：**
1. よく話し合った上で、結論を出したい。
   → 想在充分商量之后得出结论。
2. 皆さんの意見を聞いた上で、決めます。
   → 在听取大家的意见之后再做决定。
3. 内容を確認した上で、サインしてください。
   → 请在确认内容之后签字。
4. 検査した上で、病気かどうかわかる。
   → 检查之后才能知道是不是生病了。

## うちに

### 句型一

**接续：** Vる・ない／形2＋な／形1原形／名＋の ＋ うちに

**语法意思：** 在……期间／趁着……

**例句：**
1. 冷めないうちに、スープを飲んでください。
   → 请趁热把汤喝了。
2. 若いうちに、いろいろな経験をしたほうがいい。
   → 趁着年轻，最好多经历一些事情。
3. 忘れないうちに、メモしておこう。
   → 趁着没忘，先记下来吧。
4. 明るいうちに、家に帰ったほうがいい。
   → 趁着天亮，最好回家。
5. 子供が寝ているうちに、掃除をしてしまおう。
   → 趁孩子睡觉的时候，把卫生打扫了吧。

### 句型二（ないうちに）

**接续：** Vている／ない形ーない ＋ うちに

**语法意思：** 在某事发生的期间，发生了另外的一件事情。……着……／不知不觉……

**例句：**
1. テレビを見ているうちに、眠ってしまった。
   → 看着电视，不知不觉睡着了。
2. 話しているうちに、彼女の気持ちがわかってきた。
   → 说着说着，就理解了她的心情。
3. 本を読んでいるうちに、彼女から電話がかかってきた。
   → 正在读书的时候，她打电话来了。
4. 何度も練習しているうちに、上手になってきた。
   → 在反复练习的过程中，渐渐变得熟练了。
5. 知らないうちに、彼は帰ってしまった。
   → 不知不觉中，他已经回去了。

## （よ）うではないか／（よ）じゃないか

**接续：** V意志形 ＋ ではないか／じゃないか

**语法意思：** 表示建议或劝诱，包含强烈的呼吁、号召的语气。「（よ）うではありませんか」是其礼貌的表达方式。让我们……吧

**例句：**
1. もう一度、挑戦してみようではないか。
   → 让我们再挑战一次吧。
2. 一緒に歌おうじゃないか。
   → 我们一起唱歌吧。
3. この問題について、もう一度考えてみようではありませんか。
   → 关于这个问题，让我们再考虑一下吧。
4. 力を合わせて、頑張ろうではないか。
   → 让我们齐心协力，加油吧。
5. みんなで環境を守ろうじゃないか。
   → 让我们一起保护环境吧。

## 得る

**接续：** Vます ＋ 得る

**语法意思：** 表示可能性。一般用于书面语，其否定形式是「得ない」。能……

**注意：** 「～得る」表示可能性，而不表示能力。动词的可能态「～れる・られる」既可表示可能性，又可表示能力。

**例句（得る）：**
1. それはあり得ることだ。
   → 那是可能的事情。
2. 彼の成功は十分にあり得る。
   → 他的成功是十分可能的。
3. そんなことは誰にでも起こり得る。
   → 那种事情谁都可能遇到。
4. これは考え得る最善の方法だ。
   → 这是能想到的最好方法。

**例句（得ない：不可能）：**
1. そんなことはあり得ない。
   → 那种事情不可能有。
2. 彼がそんなことをするとは考え得ない。
   → 不可能想象他会做那种事。
3. それは絶対にあり得ない話だ。
   → 那是绝对不可能的事情。

## おかげで／おかげだ

**接续：** V／形1／形2／名的名词修饰形式 ＋ おかげで／おかげだ

**语法意思：** 表示原因（积极结果）。托……的福／多亏……

**例句：**
1. 先生のおかげで、日本語が上手になりました。
   → 多亏了老师，日语变好了。
2. あなたのおかげで、助かりました。
   → 多亏了你，得救了。
3. 電車が空いていたおかげで、座れました。
   → 多亏电车很空，坐到了座位。
4. 薬のおかげで、熱が下がりました。
   → 多亏了药，退烧了。
5. 彼が手伝ってくれたおかげで、仕事が早く終わった。
   → 多亏他帮忙，工作很快就结束了。
6. 天気がよかったおかげで、楽しい旅行ができた。
   → 多亏天气好，度过了一次愉快的旅行。

## ～恐れがある

**接续：** V原形／名＋の ＋ 恐れがある

**语法意思：** 表示有发生某种不好的事情的可能性。恐怕会……／有……的危险

**例句：**
1. 今夜、台風が上陸する恐れがある。
   → 今晚台风恐怕会登陆。
2. この薬には副作用が出る恐れがある。
   → 这个药有出现副作用的风险。
3. 大雨による洪水の恐れがある。
   → 有因大雨引起洪水的危险。
4. 情報が漏れる恐れがあるので、注意してください。
   → 因为有信息泄露的风险，请注意。
5. このままだと、会社が倒産する恐れがある。
   → 照这样下去，公司有倒闭的危险。
6. 鳥インフルエンザが流行する恐れがある。
   → 有禽流感流行的风险。

## ～限り（は）／～限りでは／ない限り

### １．～限り（は）

#### 接续①

**接续：** V原形・可能态／名＋の ＋ 限り

**语法意思：** 最大限度。尽量……／竭尽……

**例句：**
1. 力の限り頑張ります。
   → 我会竭尽全力努力。
2. 命の限り戦う。
   → 拼命战斗。
3. できる限り早く来てください。
   → 请尽量早点来。
4. 見渡す限りの花畑だった。
   → 是一望无际的花田。

#### 接续②

**接续：** V原形・ている／形1／形2な・である／名の・である ＋ 限り（は）

**语法意思：** 表示条件。只要……就……

**例句：**
1. 私が生きている限り、あなたを守ります。
   → 只要我活着，就会保护你。
2. 健康である限り、仕事を続けたい。
   → 只要健康，就想继续工作。
3. 雨が降らない限り、試合は行われます。
   → 只要不下雨，比赛就会进行。
4. 学生である限り、勉強しなければならない。
   → 只要是学生，就必须学习。
5. 彼が謝らない限り、許さない。
   → 只要他不道歉，我就不原谅他。

### ２．～限り／限りで（は）

**接续：** V原形・た形・ている形 ＋ 限り／限りで（は）

**语法意思：** 表示在某个限定的范围之内。据……所知／据……调查

**例句：**
1. 私の知っている限りでは、彼はまだ日本にいる。
   → 据我所知，他还在日本。
2. 見た限りでは、彼は元気そうだった。
   → 就我所看到的，他看起来很有精神。
3. 私の調べた限りでは、そんな事実はない。
   → 据我调查，没有那样的事实。
4. 聞いた限りでは、彼は来月結婚するらしい。
   → 据我所听到的，他好像下个月要结婚。

### ３．～ない限り

**接续：** Vない ＋ 限り

**语法意思：** 只要不……就不……／除非……否则就……

**例句：**
1. 雨がやまない限り、出かけられない。
   → 只要雨不停，就不能出门。
2. 彼が来ない限り、会議は始まらない。
   → 只要他不来，会议就不会开始。
3. 努力しない限り、成功はできない。
   → 只要不努力，就不会成功。
4. 謝らない限り、許してもらえないよ。
   → 除非你道歉，否则是不会被原谅的。
5. 手術しない限り、治らない。
   → 除非做手术，否则好不了。

## に限って／に限り

### １．に限って／に限り

**接续：** 名 ＋ に限って／に限り

**语法意思：** 表示限度。只限于……／只有……

**例句：**
1. このイベントは女性に限ります。
   → 这个活动只限于女性。
2. 本日限りの特別セールです。
   → 只限今天的特别促销。
3. 今日に限り、入場料は無料です。
   → 只有今天，入场费免费。
4. 中学生以下に限り、割引があります。
   → 只限于中学生以下的人有折扣。
5. 会員に限って、このサービスが利用できます。
   → 只有会员才能使用这项服务。

### ２．に限って

**接续：** 名 ＋ に限って

**语法意思：** 唯独……／偏偏……

**例句：**
1. 彼に限って、そんなことはしない。
   → 唯独他不会做那种事。
2. 大事な日に限って、電車が遅れる。
   → 偏偏在重要的日子，电车就晚点。
3. あの人に限って、嘘はつかないはずだ。
   → 唯独那个人，应该不会说谎。
4. 忙しいときに限って、客が来る。
   → 偏偏在忙碌的时候，客人就来了。

## ～に限らず～（も）

**接续：** 名 ＋ に限らず～（も）

**语法意思：** 不仅……而且……

**例句：**
1. 男性に限らず、女性もこの仕事に応募できる。
   → 不仅是男性，女性也可以应聘这个工作。
2. 日本に限らず、世界中で環境問題が注目されている。
   → 不仅是日本，全世界都在关注环境问题。
3. 子供に限らず、大人もこのアニメを楽しめる。
   → 不仅是孩子，大人也能享受这部动画。
4. この店は、平日に限らず、週末も営業している。
   → 这家店不仅平日，周末也营业。
5. 語学力に限らず、コミュニケーション能力も重要だ。
   → 不仅是语言能力，沟通能力也很重要。

## がちだ／がちの／がちな

**接续：** Vます／名 ＋ がちだ／がちの／がちな

**语法意思：** 表示倾向（客观），多指容易发生某种负面的、消极的事情。容易……／往往会……

**例句：**
1. 最近、曇りがちの天気が続いている。
   → 最近一直是阴天居多。
2. 彼は病気がちで、よく学校を休む。
   → 他经常生病，总是请假不上学。
3. 人間は怠けがちなものだ。
   → 人往往会变得懒惰。
4. 冬は風邪を引きがちだ。
   → 冬天容易感冒。
5. 年を取ると、昔の話をしがちになる。
   → 上了年纪，就容易讲过去的事情。
6. 一人暮らしは、食事が不規則になりがちだ。
   → 一个人生活，饮食容易变得不规律。
7. 彼女は悲観的に考えがちだ。
   → 她容易悲观地思考。

## （か）と思うと／（か）と思ったら

### 接续①

**接续：** Vた ＋ （か）と思うと／（か）と思ったら

**语法意思：** 表示事情几乎同时发生，后项多为意料之外的事情，包含说话人惊讶的心情。刚……就……

**例句：**
1. 電車が発車したかと思うと、すぐに止まった。
   → 电车刚发车，就马上停了下来。
2. 彼は起きたかと思うと、また寝てしまった。
   → 他刚起来，就又睡着了。
3. 子供は学校から帰ってきたかと思うと、すぐに遊びに出かけた。
   → 孩子刚从学校回来，就马上出去玩了。
4. 雨が降り出したかと思うと、すぐにやんだ。
   → 刚下起雨来，马上就停了。

### 接续②

**接续：** V基本形・た ＋ かと思うと／と思ったら（负面）
